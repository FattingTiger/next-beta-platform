### Round 2：Web 界面、异常和恢复

## 二、Android 客户端三轮验收

### Round 1：真实功能闭环

- 覆盖安装最终 Debug APK 后，已有测试用户会话正常保留。
- 应用列表、搜索、详情、版本、Logo、两张受控截图和更新信息加载成功。
- 从公网下载 QA APK，客户端完成大小、SHA-256、包名、版本号和签名校验。
- 下载结果 SHA-256 为 `ca451771cd6735bf12fd724efb1b81036607bd6ff03d422318abd56772dedb46`，与服务端固定制品一致。
- 成功进入 Android 系统 PackageInstaller，并显示 `QA 试验场` 更新确认界面。
- Bug `BT-C407142D` 的提交、截图上传、管理员评论、处理中、待验证、测试用户验证通过和关闭结论形成完整闭环。
- 本人提交且仍为“待处理”的 Bug 支持编辑标题、描述和复现步骤；管理员开始处理后服务端返回稳定冲突并锁定历史文本。
- 最终 APK 覆盖安装后另行完成“新建私有 Bug + 2 张安全测试图 + 编辑三项文本 + 返回列表刷新 + 重新进入详情”验收，编辑内容和两张附件均保持。
- 最终崩溃日志为 0。

### Round 2：界面、可访问性和恢复

- 亮色、暗色、1.5 倍字体和横屏布局均完成截图与语义树检查，无关键按钮丢失或文本不可达。
- Detail 与 Bug Detail 在应用进入后台、进程被系统回收后可恢复原目标对象；账号变化时不会恢复旧账号页面。
- 空搜索状态、加载状态、断网错误和网络恢复后的刷新均通过。
- 断网测试发现并修复了底层 IP/端口直接显示的问题；最终仅显示“网络连接失败，请检查网络后重试”。
- 缩略图与大图使用独立缓存规格；大图包含加载、失败重试、1–5 倍缩放、平移边界、双击和复位策略。

### Round 3：并发、安全和资源

- 15 次快速刷新、8 组搜索切换以及 20 次 Bug 筛选切换后，最终查询与列表一致，无旧请求覆盖新状态。
- 下载任务在断网等待时可取消；最终界面显示“重新下载”，用户目录文件数为 0。
- 下载目录、WorkManager 标签和唯一任务名按用户 SHA-256 键隔离；READY 文件必须属于当前用户。
- 发现并修复“点击退出后立即杀进程会恢复旧会话”的竞态。最终复验：重启只显示登录页，会话文件只剩代际号，下载文件为 0。
- 会话使用 Android Keystore AES-GCM；退出先持久化 retirement 屏障，再有界取消下载、清文件、清会话并撤销令牌。
- 12 次反复打开/关闭鉴权大图后，PSS 从 128,144 KB 增至 137,581 KB，增量 9,437 KB，符合有界缓存预期。
- 对应用私有目录和最终 logcat 重新采集并扫描：明文 access token、refresh token、Authorization、Bearer 值和完整中国手机号命中均为 0；证据只保存聚合计数，不保存私有内容。
- API 同源策略测试覆盖相对 URL、同源绝对 URL、跨主机、跨协议、跨端口、伪装子域和 userinfo URL。
- 登录和首次改密字段不进入 SavedState，避免密码或手机号随系统状态包持久化。
- PATCH 使用禁重定向、同源受限的 OkHttp 通道；协程取消会调用 `Call.cancel()`，退出或切换账号不会让旧账户编辑请求继续悬挂。
- 44 项 JVM 单元测试通过，0 失败、0 错误、0 跳过；Android Lint 只有构建工具可升级提醒。
- Debug 与经 R8 收缩的 unsigned Release 构建均成功；Debug APK 使用 Android Debug 证书并通过 APK Signature Scheme v2 校验。

## 五、已知边界与上线前动作

1. 当前客户端正式 Release 包未配置公司签名，不能把 unsigned Release 当作员工发布包；需要生成并离线保管正式 keystore，再重跑三轮客户端验收。
2. 最终 Android 真机兼容矩阵仍建议覆盖至少 Android 8/10/12/14/16 各一台员工常见机型；本轮动态证据来自 Android 16 模拟器。
3. 客户端刷新会展示服务端最新版本与更新内容，但尚未自动比对设备已安装应用的 versionCode，因此没有可靠区分“首次获取”和“更新”的按钮状态；本项已在评分中扣 1 分。
4. 平台按需求不包含静默安装、强制升级、远程卸载、恶意代码扫描、双人审核、提醒和外部合作方账号。
5. 继续监控 Caddy 的短期 IP 证书自动续期，并保留定期备份恢复演练。
